# Foro Gaming

## Descripción

Este proyecto consiste en el desarrollo de una página web tipo foro orientada a la temática de videojuegos. El sitio permite a los usuarios visualizar contenido, interactuar con publicaciones y simular el funcionamiento básico de una comunidad online.

---

## Estructura del sitio

El desarrollo fue realizado utilizando HTML, aplicando etiquetas semánticas para organizar el contenido:

* Encabezado (header) con menú de navegación
* Contenido principal (main) dividido en secciones
* Pie de página (footer)

---

## Contenido incluido

El sitio web cuenta con los siguientes apartados:

* Sección de login de usuario
* Página de inicio con acceso a contenido externo
* Foro con publicaciones de distintos formatos
* Tabla de usuarios con actividad
* Formulario de contacto

---

## Multimedia

Se incorporan distintos tipos de recursos multimedia:

* Imágenes almacenadas localmente
* Videos mediante etiqueta video
* Video embebido desde YouTube mediante iframe
* Audio mediante etiqueta audio
* Documento en formato PDF

---

## Funcionalidades

El sitio simula las siguientes acciones:

* Creación de publicaciones
* Interacción mediante botones (like/dislike)
* Comentarios en publicaciones
* Navegación interna mediante enlaces
